# Group Activity Bank

## When To Use
Every session ends up with the same two breakout formats, and the group can tell. Use this when the blocks are set and you need a method for each that fits its job, the headcount and the time. It answers: what could carry this block, why that one, and how does it run step by step?

## When Not To Use
For the first activity of the day, use Icebreakers and Session Openers. When the skill is a conversation people must practise, use Role-Play Practice Kit. Where an exercise sits in the flow is decided in Workshop Agenda; this skill writes how it runs.

## Inputs
- The blocks, with the job of each and the minutes it has.
- The headcount, the roles in the room, and whether it is a room or a video call.
- The formats this group has already had too often.
If you have none of this, I start from one block, its job and the headcount and mark the output as a first draft.

## Approach
Public group methods, each from its originator: 1-2-4-All and Troika Consulting from Liberating Structures, on its originators' site (shared under a Creative Commons licence), World Café from the World Café Community Foundation, and the Jigsaw Classroom, on its originator's site. These pages describe how the methods run; they are not effectiveness studies. The judgment is fit: an activity is chosen for the block's job. The failure this prevents: a lively carousel of tables in a block that had to end in a decision, and no decision.

## Workflow
1. Ask at most three questions: what is each block's job and how long is it, how many people in which roles, and which formats has this group had enough of?
2. Name each block's job as one of five: open up, go deep, teach each other, practise, narrow down. Choose by job, headcount and time, and say why. Two or three options per block, never a longer list.
3. To get every voice in, 1-2-4-All: one question; silent individual reflection, then pairs, then fours, then a few ideas shared with the whole group. Minimum four people. The originators suggest about a minute alone, two in pairs, five in fours and a short share-out; you set the real time. It needs a sharp question or the answers are thin. As the first exercise of the day the same format belongs to Icebreakers and Session Openers, so here it carries a block inside the session.
4. To go deep, Troika Consulting: trios, one "client" with a real challenge and two "consultants". The client presents, the consultants ask clarifying questions, the client turns away and listens while they discuss, then says what was most useful; rotate. Or World Café: tables of four (five at most), three or more rounds with a question per round, people move while a table host may stay, then a whole-group harvest. It is weak when the block must end in a decision.
5. To teach each other, Jigsaw: split the material into segments, one per person; "expert groups" with the same segment prepare together; back in home groups each person teaches their segment and takes questions. It was built for classrooms and the original ends with a quiz, which is left out here.
6. To narrow down, generic methods with no originator named: think, pair, share; silent writing, a round robin, clarifying, then a vote; brainwriting; affinity clustering; dot voting, which shows popularity and is not a decision.
7. Write each option as a run list, then you answer one check per activity before it goes into the plan: "Does this activity make people do the thing, or only talk about it?" What fails comes out.

## Output Format
```markdown
# Group Activity Bank
Session: [title] | Group: [number, roles] | Format: [room / video call]
## Options by block
| Block and its job | Option | Method and source | Why it fits this job, headcount and time | Trade-off |
|---|---|---|---|---|
| [block]: [open up / go deep / teach each other / practise / narrow down] | A | [method, source] | [reason] | [trade-off] |
| [same block] | B | [method, source] | [reason] | [trade-off] |
## Run list: [block], option [letter], [method]
Question put to the group: [the exact question]
1. [step] ([minutes, set by the trainer])
2. [step] ([minutes])
3. [step] ([minutes])
Materials: [list] | Virtual variant: [how it runs on a call] | If it lands flat: [fallback]
## Checks
| Activity | Does it make people do the thing, or only talk about it? | Kept or dropped |
|---|---|---|
| [activity] | [the trainer's answer] | [kept / dropped] |
## Decision
[Trainer] chooses one option per block by [date], before the run sheet is written.
```

## Done When
- Every block has two or three options, each with its source and a reason tied to the job, the headcount and the time.
- Every run list has the exact question, steps, timings as placeholders, materials, a virtual variant and a fallback.
- You have answered the check for every activity, and anything that only makes people talk about the thing is out.

## Quality Bar
- A weak question sinks a good method, so the question is written out in full, about this group's work.
- Timings are yours; an originator's suggestion is quoted as a suggestion.
- No claim that a method "works"; the sources describe the steps.
- Nothing is strung together for variety: one method per block, chosen for its job, and a format already used as the opener is not offered again unless you ask for it.
- Claude proposes and writes the run lists; you choose what fits this group, and no activity asks for personal disclosure or sorts people into types.
