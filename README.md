# Claude Skills Marketplace — themed skill packs for Claude Code and Claude.ai

**37 free Claude Skill packs, 1073 skills in all, for Claude Code and Claude.ai.** They cover people ops and HR, management and leadership, recruiting, customer service, product and project management, L&D and corporate training, design thinking, design sprints, DesignOps and design leadership, innovation, proposals and case studies, graduate and early-career work including a first job, LinkedIn, networking and junior marketing, French public-procurement bids, French B2B field sales, French annual-review and career-path interview campaigns, French recruiting end to end under French labour law, the whole French HR year under French labour law, pricing your expertise under AI pressure, an authentic LinkedIn presence for founders and consultants, finding clients for people who sell their own expertise, winning clients through your own network on LinkedIn, UX and user research, winning proposals when the client has AI too, and workshop facilitation. Each pack installs as one Claude Code plugin, or as one zip per skill on claude.ai, and is free to use inside your company.

**Claude Skills** (also called **Agent Skills**) are folders containing a `SKILL.md` file that teach [Claude](https://claude.ai) how to do a specific job the way *your* team does it. This repository is a **marketplace of themed skill packs**: each pack bundles a set of skills plus the reference files they share, around one real job to be done.

> **Install everything in one line (Claude Code):**
> ```
> /plugin marketplace add polar-bear-org/claude-skills
> ```

**[Browse all packs with guides](https://meet-polar-bear.com/skills)**: one page per pack, with a guide and a download.

Built and maintained by [Polar Bear](https://meet-polar-bear.com) ([LinkedIn](https://www.linkedin.com/company/polar-bear-people-ops/)), a people ops consultancy for human-size teams (20–200 people), founded by ex-McKinsey consultants. These are the skills we run our own company on.

## Install

There are three ways to install, depending on where you use Claude.

### 1. Claude Code — plugin marketplace (recommended)

Inside a Claude Code session:

```
/plugin marketplace add polar-bear-org/claude-skills
/plugin install workshop-pack@polar-bear-skills
```

That is it. The skills load automatically and Claude picks the right one when you describe the task ("help me structure a 3-hour session on pricing"), or you can call one by name ("run intention-framer").

To update later: `/plugin marketplace update polar-bear-skills`.

### 2. Claude.ai (web, desktop, mobile) — upload the zips

Every pack ships ready-to-upload zips in its `install/` folder, one per skill.

1. Turn on **Settings → Capabilities → Code execution and file creation** (skills require it).
2. Go to **Settings → Customize → Skills → Upload skill**.
3. Upload one zip per skill.
4. Add the pack's files from `resources/` to your Claude Project as project knowledge.

### 3. Manual — copy the folder

Skills are just folders. Copy any skill into your skills directory:

```bash
git clone https://github.com/polar-bear-org/claude-skills.git
cp -r claude-skills/packs/workshop-pack/skills/* ~/.claude/skills/     # personal, all projects
# or
cp -r claude-skills/packs/workshop-pack/skills/* .claude/skills/       # this project only
```

## FAQ

**What is a Claude Skill?**
A Claude Skill (Agent Skill) is a folder with a `SKILL.md` file: YAML frontmatter giving the skill a `name` and a `description`, followed by Markdown instructions. Claude reads the description to decide when the skill applies, then loads the full instructions only when it is needed. Skills work in Claude Code, Claude.ai, and the Claude Agent SDK.

**What is a skill pack?**
A skill pack is several related skills plus their shared reference files, distributed together as one installable unit. A pack covers a whole workflow rather than a single step — the Workshop Pack, for example, spans intention through retro, and each skill hands off to the next.

**How do I install a skill pack from GitHub into Claude Code?**
Run `/plugin marketplace add polar-bear-org/claude-skills` in a Claude Code session, then `/plugin install <pack-name>@polar-bear-skills`. Claude Code reads [`.claude-plugin/marketplace.json`](.claude-plugin/marketplace.json) at the repository root to find the packs.

**Can I use these skills on claude.ai instead of Claude Code?**
Yes. Each pack's `install/` folder holds one zip per skill, ready for **Settings → Customize → Skills → Upload skill**. Enable code execution first, under Settings → Capabilities.

**Do these skills replace the facilitator?**
No. In the Workshop Pack, Claude designs and captures; humans facilitate. No skill here runs the room. They take everything around the craft off your plate.

**Can Claude run user research for me?**
No, and the Design Thinking Pack is explicit about it: Claude prepares and synthesises, humans meet the users. Every persona, insight and finding it produces is built from research with real people, and the skills say when it is time to go and talk to them.

**Do I need performance review software to run a review cycle?**
No. The Annual Review Cycle Pack runs the whole cycle — growth matrix, review forms, self-reviews, manager growth memos, 1:1s, retro — in Claude plus a shared folder of Markdown files. It is built for teams of 20–200, where per-seat performance software costs more than it returns.

**Do I need onboarding software to onboard a new hire?**
No. The Onboarding Pack runs the whole journey — pre-boarding plan, IT and finance setup emails, welcome brief, welcome pack, per-joiner checklist and dashboard, team deck, intro email, first goals, first week, and the joiner's own 90-day companion — in Claude plus a shared folder of Markdown files. Claude prepares and keeps track; the welcome itself stays human.

**Can Claude run a design sprint for us?**
No, and the Design Sprint Pack is explicit about where the line sits: Claude qualifies, frames, casts, scouts, captures, and synthesises, and it will even put concepts on the wall on sketch day — but no concept of its own reaches the vote unless a human puts their name on it, and the heat map, the Decider's call, and the five Friday conversations stay human throughout.

**Can Claude write my graduate application or sit my assessment centre?**
No, and Claude for Business Graduates holds one line throughout: Claude helps you prepare, practise, research, organise and critique your own work. It never sits a test, interview or assessment for you, never invents experience or results, and never writes assessed work unless your university's rules allow it and you say so. Nothing goes to an employer that you have not checked and cannot explain yourself.

**Can Claude help me in my first job without doing it for me?**
Yes, and Nail Your First Job with Claude holds one line throughout: Claude helps you learn the job faster and check your own work. Your employer's AI policy comes first, nothing it keeps confidential goes in, Claude never invents what you did, and nothing it drafts goes out in your name until you have read it, checked it and chosen to send it. The pack's AI Task Picker exists for exactly this — it names what you should keep doing by hand in order to learn the job.

**Can Claude write marketing copy and campaign plans for a brand that is not mine?**
It can draft them, and Claude for Marketing Graduates is built so a person stays accountable for what goes out. Brand copy follows the brand's own voice guide, every AI draft goes through a line-by-line review that records what was checked, kept, changed and cut, and every claim goes through a substantiation check: the pack never invents a statistic, a result, a review, a testimonial or a customer quote, so every claim in your copy traces to evidence someone holds. Advertising, consumer law and data protection points end with "check with a qualified adviser". Applications, posts and interview answers stay in your own words, from your own experience.

**Are the skills free? What is the license?**
Yes, free to use inside your company, not for resale. You may use them for your own team, your own company and your own client work, adapt them for that use, and share them with colleagues inside your organization. You may not sell, sublicense or redistribute them or derivatives as a paid product, template or course, or present them as your own work when redistributing them publicly. They are provided as is. See [LICENSE](LICENSE.md).

**Do they work with ChatGPT, Gemini or other assistants?**

**Where can I see each pack before installing it?**
Every pack has a page at [meet-polar-bear.com/skills](https://meet-polar-bear.com/skills) with a guide and a zip download. The address is `meet-polar-bear.com/skills/<pack-name>`, for example [meet-polar-bear.com/skills/ai-for-hr-pack](https://meet-polar-bear.com/skills/ai-for-hr-pack).

**Should I lower my prices because I use AI?**
That is the question Pricing Under AI Pressure is built to answer, and it answers it from your numbers rather than from a rule. The AI Activity Map measures, activity by activity on real jobs, where AI actually saves time and what new work it adds; the AI Cost Ledger puts your tool and API bills next to that; and the AI Savings Decision then has you choose, per service, whether to pass the saving on, keep it as margin or reinvest it, with the line you will say to clients. The pack never sets a price for you, never invents a benchmark or a competitor's rate, and never hides your use of AI — the AI Disclosure Policy is there for the opposite reason.

**Where will my next client come from if I only sell between delivery days?**
That is the problem the Claude Guide for Finding Clients starts from. The Business Development Plan sets one 90-day goal from your own numbers, a warm-first channel mix and 2 or 3 weekly actions you control; the Weekly Business Development Hour makes it a fixed slot that survives a busy delivery week; and the Pipeline Review stages every open deal by what the buyer actually did, so a full-looking pipeline stops hiding stale deals. Warm comes before cold throughout: past clients, key accounts, referrals and your own network first, and cold outreach only as one person on one real public trigger. Claude researches, prepares and drafts from your real work and real clients — you choose who to talk to, put it in your own words and send it yourself.

**What do I say when a client says AI could do this in 10 seconds?**
That is the objection Claude for Winning Proposals is built around. AI Objection Answer splits the work task by task — what AI genuinely does well here, said first and without selling against it, what stays with you, and an option where the client does part of it with their own AI. Like-for-Like Quote Comparison levels your scope against a cheaper AI-first quote line by line, AI Use Statement puts your own AI use in the proposal in plain words, and Fee Structure Choice shows where AI speed changes the math on how you charge.

**Can I add my own pack?**
Yes — see [CONTRIBUTING.md](CONTRIBUTING.md). It covers creating a pack from scratch, bringing in a pack that already exists, adding a skill to a pack, and editing one.
